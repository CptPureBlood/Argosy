# Mare Nostrum

A Tradewinds-inspired Mediterranean ship-trading game (English / Türkçe). Vanilla JS + Canvas, wrapped with Capacitor into an Android APK.

## Play in a browser
Open `www/index.html` (or serve `www/`).

## Get the APK
Every push to `main` builds a debug APK via GitHub Actions. Download `Mare Nostrum.apk` from the **Releases → latest** page, or from the workflow run's artifacts.

## Develop
    npm install
    npm test        # logic simulation tests
